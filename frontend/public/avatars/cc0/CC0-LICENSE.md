# CC0-1.0 Avatar Assets

The `.glb` files in this directory (`base_body_anim.glb`, `clothing_*.glb`, `hair_*.glb`) are **CC0-1.0 (Public Domain)** 3D character assets derived exclusively from MakeHuman system assets (`makehumancommunity.org`) and CC0-released generated meshes from `kblood/CharacterCreator` (`output/`).

No GPL code is included in this project; only the CC0-1.0 binary `.glb` data files are used.
